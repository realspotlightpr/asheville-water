# Meta Pixel tracking

- Pixel ID: `1914962299182018`
- Consent category: Analytics
- Script source: `https://connect.facebook.net/en_US/fbevents.js`
- Event: `PageView`
- Trigger: Initial page and each client-side route change, only after analytics consent
- Direct contact information: Not included
- Noscript beacon: Intentionally omitted because it cannot honor JavaScript consent state
- Withdrawal: Disabling analytics in Cookie Settings reloads the page without initializing the pixel

Validate production events in Meta Events Manager and use Test Events before relying on campaign attribution.
